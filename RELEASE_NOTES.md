Prima versione di MG4 Task Manager.

- Lista delle app aperte, chiusura singola e «Chiudi tutto»
- Funziona senza PC: si installa da chiavetta USB
- Con ADB dell'auto attivo: chiusura istantanea e aggiornamenti silenziosi
- Senza ADB: chiusura tramite accessibilità («Forza interruzione» automatico)
- App di sistema escluse e nascoste (attivo di default), app escluse a scelta
- Apertura con tasto al volante configurabile
- Aggiornamenti automatici in background dalle Release di GitHub
